# Contributing

`v3/catalog.json` and `v3/common_types.json` are copies of release assets from [kaltura-a2ui-components](https://github.com/kaltura/kaltura-a2ui-components). Change the catalog there, not here. See "Update the catalog" in the README.

Examples in `v3/examples/` use the shape `{name, description, messages}`. Run `npm run validate` before you open a pull request.
