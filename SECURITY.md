# Security

Report a vulnerability through [GitHub private vulnerability reporting](https://github.com/kaltura/a2ui/security/advisories/new). Do not open a public issue.

This repo holds JSON only. The catalog describes components. It does not run code. Renderer security is covered in [kaltura-a2ui-components](https://github.com/kaltura/kaltura-a2ui-components/blob/main/SECURITY.md).
